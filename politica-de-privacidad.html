2. Finalidad de la web

El sitio web tiene como finalidad proporcionar información y herramientas relacionadas con el cálculo orientativo del salario neto en España.

La calculadora permite al usuario introducir determinados datos para obtener una estimación del salario neto correspondiente a los parámetros introducidos.

3. Datos introducidos en la calculadora

Los datos introducidos directamente en la calculadora se utilizan para realizar los cálculos solicitados por el usuario.

La herramienta está diseñada para realizar los cálculos en el propio navegador del usuario y no requiere, para realizar una estimación, crear una cuenta de usuario.

Se recomienda no introducir información personal que no sea necesaria para utilizar la herramienta.

4. Formularios de contacto

Cuando el usuario utiliza un formulario o medio de contacto disponible en el sitio web, los datos facilitados serán tratados con la finalidad de atender y responder a la consulta realizada.

Los datos deberán ser adecuados, pertinentes y limitados a lo necesario para gestionar la solicitud.

La base jurídica del tratamiento dependerá de la finalidad concreta para la que se recopilen los datos y podrá incluir el consentimiento del usuario, la ejecución de una solicitud realizada por el usuario o el cumplimiento de obligaciones legales cuando corresponda.
